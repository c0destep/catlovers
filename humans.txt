# TECHNOLOGY COLOPHON

  ## FRONTEND
    HTML5, CSS3, JavaScript (ES6+)
    PostHTML -- HTML preprocessing
    Parcel -- Bundler and build tool
    simple-translator -- Internationalization (i18n)
    Modernizr -- Feature detection
    Normalize.css -- CSS reset

  ## TESTING
    Cypress -- End-to-end testing
    ESLint -- JavaScript linting
    Stylelint -- CSS linting
    Prettier -- Code formatting

  ## DESIGN
    Fonts: Manrope (body), Fraunces (display) -- Google Fonts
    Color scheme: Custom purple/rose palette with CSS custom properties
    Methodology: BEM (Block Element Modifier)
    Responsive: Mobile-first approach

  ## SERVER & DEPLOYMENT
    Apache HTTP Server
    .htaccess configuration for compression and caching
    Service Worker for offline support and caching
    GitHub Pages for hosting

  ## DEVELOPMENT TOOLS
    Node.js -- JavaScript runtime
    pnpm -- Package manager
    Git -- Version control
    VS Code -- IDE

  ## VERSION
    Current version: 1.0.0
    Service Worker cache version: v5
