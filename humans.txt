    HTML5, CSS3, JavaScript (ES6+)
    Vite -- Multipage bundler and development server

    Browser-native translator -- Internationalization (i18n)
    Custom preflight -- CSS reset

  ## TESTING
    Cypress -- End-to-end testing
    ESLint -- JavaScript linting
    Stylelint -- CSS linting
